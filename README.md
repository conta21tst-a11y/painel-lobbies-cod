# Squad Agora

Arquivos prontos para GitHub Pages.

1. Crie ou abra um repositório no GitHub.
2. Envie `index.html` e `squad-agora-online.js` para a raiz do repositório.
3. Em **Settings > Pages**, escolha **Deploy from a branch**, selecione `main` e a pasta `/(root)`.
4. Salve e aguarde o link público.

O projeto usa apenas a chave pública do Supabase. Nunca envie ou publique uma chave `sb_secret_`.
